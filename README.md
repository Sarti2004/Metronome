# Metronome for MacroDeck 3

A simple metronome widget for MacroDeck 3 with tap tempo, adjustable BPM, and click sound selection.

## Features

- Set and fine-tune tempo from 30 to 300 BPM
- Tap tempo to match a beat quickly
- Visual beat indicator and slider-based tempo control
- Choose from built-in click sounds in the widget settings

## Installation

1. Open Macro Deck on your PC.
2. Go to `Store`.
3. Search for `Metronome`.
4. Click `Install`.
